## Spacing Scale

Base unit: 4px. All values are multiples of 4.

| Token | Value | Usage |
|-------|-------|-------|
| `space-1` | 4px | Icon-to-label gap, badge inner padding vertical |
| `space-2` | 8px | Compact spacing, chip horizontal padding (small), between inline elements |
| `space-3` | 12px | Card inner padding (tight), pill vertical padding |
| `space-4` | 16px | Default horizontal screen padding, standard element gap |
| `space-5` | 20px | Screen header padding, card body padding |
| `space-6` | 24px | Section gap, sheet top padding |
| `space-8` | 32px | Major section breaks, hero bottom padding |
| `space-10` | 40px | Tab bar padding reference, large section spacer |
| `space-12` | 48px | Full-screen center empty-state top margin |

> Extended standard set for React Native: {4, 8, 12, 16, 20, 24, 32, 48, 64} — values 12 and 20 are included for iOS HIG alignment (iOS system uses 12px inter-item gaps and 20px section margins natively). All values are multiples of 4.

**Exceptions:**
- Touch targets: minimum 44px (iOS HIG) — all interactive elements must meet this regardless of visual size
- Tab bar: iOS 80px height (24px safe area bottom), Android 68px height (8px bottom padding)
- Bottom sheet drag handle: 4px height, 40px width, centered, 12px top margin
- Horizontal screen padding: always 16px (space-4) except full-bleed hero images

## Typography

System font stack only. No remote font loads (app size constraint: iOS < 40MB, Android < 30MB).

**Formal type scale — exactly 4 sizes, exactly 2 weights:**

| Role | Size | Weight | Line Height | Letter Spacing | Color Default | Usage |
|------|------|--------|-------------|----------------|---------------|-------|
| Display | 36px | 700 | 1.15 | -0.5 | `cream` (#F5EDD6) | Hero greeting ("Good morning, Dami"), wallet balance amount; use `fontVariant: ['tabular-nums']` variant for numeric balance display |
| Heading | 22px | 700 | 1.25 | -0.3 | `ink` | Section headings, card headers, modal titles, screen tab headers, driver name in trip card, property name in detail |
| Body | 14px | 400 | 1.50 | 0 | `ink` | Primary readable text, message bubbles, descriptions, menu item labels, card titles, tab labels (use weight 700 for emphasis variant) |
| Caption | 12px | 400 | 1.40 | 0.2 | `ink-secondary` | Timestamps, metadata, category badges, section labels (all-caps at 0.7 opacity replaces former Overline role) |

**Body emphasis variant** (same row in implementation, not a separate named role):
- Size: 14px, Weight: 700, Line Height: 1.50 — used for menu item labels, card titles, button labels, price chips, active states

**One-off component override (not a named system role):**
- Countdown number: 48px, weight 700, gold — used exclusively in the CountdownRing component (`mobile/app/transport-flow.tsx`, matching screen). Declared here as a component-level override only; do not add to the type scale.
  // component-level override — sole exception to the 4-size type scale; not a named role

**Rules:**
- Display and numeric balance use tabular numeric spacing (`fontVariant: ['tabular-nums']` on Android/iOS)
- No font size smaller than 12px
- No font size smaller than 12px for interactive labels
- Letter spacing -0.5 on all sizes 22px and above
- Body line height 1.5 is mandatory for readability on all message/description text
- Former Overline role (11px, all-caps labels) replaced by Caption (12px) at `opacity: 0.7` — apply this opacity at the StyleSheet level wherever section-label treatment is needed
- Former Subheading role (18px) replaced by Heading (22px) — all previous Subheading usages map to Heading
- Former Title role (28px) consolidated to Heading (22px)

## Interaction Specifications

### Animation Constants

All Reanimated spring configs:

```typescript
// Card press
const cardPressConfig = {
  stiffness: 300,
  damping: 20,
  mass: 1,
};

// Button press
const buttonPressConfig = {
  stiffness: 400,
  damping: 25,
  mass: 0.8,
};

// Sheet entry
const sheetEntryConfig = {
  stiffness: 250,
  damping: 28,
  mass: 1,
};

// Number reveal (wallet)
const numberRevealDuration = 600; // ms, Easing.out(Easing.cubic)
```

### Haptic Map

| Action | Haptic |
|--------|--------|
| Primary button press | `Haptics.impactAsync(ImpactFeedbackStyle.Light)` |
| Card press | none (scale animation is sufficient) |
| Vehicle type select | `Haptics.selectionAsync()` |
| Quick action pill press | `Haptics.selectionAsync()` |
| Driver mode toggle ON | `Haptics.impactAsync(ImpactFeedbackStyle.Medium)` |
| Driver mode toggle OFF | `Haptics.impactAsync(ImpactFeedbackStyle.Light)` |
| Ride matched | `Haptics.notificationAsync(NotificationFeedbackType.Success)` |
| Booking confirmed | `Haptics.notificationAsync(NotificationFeedbackType.Success)` |
| QR scan success | `Haptics.notificationAsync(NotificationFeedbackType.Success)` |
| QR scan fail | `Haptics.notificationAsync(NotificationFeedbackType.Error)` |
| Destructive confirm | `Haptics.notificationAsync(NotificationFeedbackType.Warning)` |
| Wallet balance reveal | none |
| Star rating select | `Haptics.selectionAsync()` |

### Tab Transitions

```
Animation: fade opacity 0→1 over 200ms, Easing.inOut(Easing.ease)
No slide transitions on tab switch (avoid motion sickness on mobile)
Tab icon scale: 1.0 → 1.12 → 1.0 on activate, spring (stiffness 500, damping 30)
```

### Search Morphing

```
Collapsed: standard search bar row (52px height, 14px radius)
Expanded: Animated.timing, duration 250ms, Easing.out(Easing.quad)
  Height expands to screen height
  Blur backdrop fades in: opacity 0→1
  Input gains gold focus border
  Keyboard raises automatically
Collapsed: reverse animation on "Cancel" or back gesture
```

### Skeleton Shimmer

```
Animated.loop(
  Animated.sequence([
    Animated.timing(shimmerAnim, { toValue: 1, duration: 800, useNativeDriver: false }),
    Animated.timing(shimmerAnim, { toValue: 0, duration: 800, useNativeDriver: false }),
  ])
)
backgroundColor interpolates: surface-raised → surface-high
No opacity change — color interpolation only
```
