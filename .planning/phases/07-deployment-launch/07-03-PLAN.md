    ```markdown
    ### LAUNCH-07: 5-Minute Rollback Procedure

    Railway automatically keeps the last 10 deployment images. To rollback:

    1. Open Railway dashboard → your service → "Deployments" tab
    2. Find the previous successful deployment (green checkmark)
    3. Click the three-dot menu → "Redeploy"
    4. Railway spins up the previous image (typically 2-3 minutes)
    5. Verify: curl https://iseyaa-api.up.railway.app/api/v1/health

    **To test the rollback procedure (required before soft launch):**
    1. Deploy a deliberately broken commit (e.g., add `throw new Error('test rollback')` to health endpoint)
    2. Confirm health check fails
    3. Follow steps 1-5 above
    4. Confirm health check passes again
    5. Total time should be under 5 minutes

    **Database rollback:** If a migration was applied, Railway rollback does NOT roll back the DB schema.
    - Keep a Neon branch snapshot before each deployment
    - To revert schema: `npx prisma migrate resolve --rolled-back <migration-name>` then apply the correct migration
    ```
