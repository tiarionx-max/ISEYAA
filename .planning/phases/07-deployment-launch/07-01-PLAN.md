<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| EAS Build cloud → app binary | EAS runs builds on Expo's servers; credentials stored in EAS Credentials service, not in repo |
| Internal distribution → testers | APK links expire; only people with the EAS project access can download |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Information Disclosure | EXPO_PUBLIC_API_URL hardcoded in eas.json | accept | This is the public API URL — not a secret. The env key is intentionally EXPO_PUBLIC_* which means it's bundled into the app binary |
| T-07-02 | Tampering | Production app-bundle profile used accidentally in dev | mitigate | Separate profiles with distinct distribution modes (internal vs store) prevent accidental production submissions |
</threat_model>
