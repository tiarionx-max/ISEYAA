    **Prerequisites (one-time setup):**
    - [ ] Apple Developer account enrolled at developer.apple.com ($99/year)
    - [ ] App created in App Store Connect: name "ISEYAA", bundle ID ng.gov.ogun.iseyaa
    - [ ] Google Play Console account ($25 one-time): create app with package ng.gov.ogun.iseyaa
    - [ ] EAS account at expo.dev (free) — run `npx eas-cli login`
    - [ ] Run `npx eas-cli init` inside mobile/ to link to your EAS project and get the projectId

    **Step 1 — Build for stores:**
    ```bash
    cd mobile
    npm run build:ios       # eas build --profile production --platform ios
    npm run build:android   # eas build --profile production --platform android
    ```
    Monitor at: https://expo.dev/accounts/[username]/projects/iseyaa/builds

    **Step 2 — Verify sizes before submission:**
    - iOS IPA: must be < 40MB (download from EAS build page and check)
    - Android AAB: must be < 30MB (Google Play compresses further)
    - If over limit: run `npm run atlas` (Expo Atlas) to find large modules, then optimize

    **Step 3 — Submit iOS to TestFlight:**
    ```bash
    npm run submit:ios      # eas submit --profile production --platform ios
    ```
    Then in App Store Connect:
    - Navigate to TestFlight tab
    - Add testers via email (50+ required for LAUNCH-05)
    - Invite using "Add Testers" → External Groups

    **Step 4 — Submit Android to Play Store internal track:**
    ```bash
    npm run submit:android  # eas submit --profile production --platform android
    ```

    - Play Console > Setup > API access > Create service account > Grant "Release manager" role
    - Save as mobile/google-service-account.json (do NOT commit — add to .gitignore)

    **Step 5 — Development build for immediate testing (DO THIS FIRST):**
    ```bash
    npm run build:dev:android   # fastest path to install on your Android device
    ```
    Once complete: scan QR code in EAS dashboard to install APK directly on device.
    For iOS: install via TestFlight after build:dev:ios completes.

    **Size optimization if over limit:**
    - Remove unused Expo SDK modules from app.json plugins
    - Check if react-native-maps is included (large dependency)
    - Run: EXPO_UNSTABLE_ATLAS=true npx expo export --platform ios && npx expo-atlas
    ```
