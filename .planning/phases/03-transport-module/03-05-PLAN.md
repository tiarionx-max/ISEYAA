<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public internet → REST `/api/v1/transport/*` | Authenticated routes guarded by JWT + Roles; fare-estimate is public (read-only computation, no PII) |
| WebSocket client → Gateway | Token verified on connect; subscribe handlers cannot be reached without valid JWT |
| Driver socket → Other rider's trip room | Drivers can only join trip rooms they own; mobile client must be trusted to call join:trip with correct id |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-19 | Spoofing | Unauthenticated WebSocket connection | mitigate | `handleConnection` requires `handshake.auth.token`; missing or invalid → immediate `client.disconnect()` |
| T-03-20 | Information Disclosure | Driver location broadcast to all sockets | mitigate | All emits use `server.to('trip:{tripId}')` or `server.to('driver:{driverId}')` — never `server.emit()` (verified by grep gate in acceptance) |
| T-03-21 | Tampering | Driver requests join to a trip room they aren't part of | accept (Phase 6) | MVP: client trusted to send correct tripId; Phase 6 will validate that connected userId matches trip.driverId or trip.riderId before allowing join |
| T-03-22 | Elevation of Privilege | Citizen calls /transport/drivers/:id/approve | mitigate | `@Roles(UserRole.LGA_ADMIN)` guard rejects with 403 |
| T-03-23 | Denial of Service | Single client opens many WS connections | accept (Phase 6) | Throttler covers HTTP; WS connection limit per IP deferred to Phase 6 hardening |
</threat_model>
