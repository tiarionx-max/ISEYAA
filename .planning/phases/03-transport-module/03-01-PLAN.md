## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TransportService → RedisService | Geo coordinates supplied by service after server-side validation; Redis must not accept untrusted lat/lng directly |
| External callers → WalletService.creditWallet | Only same-process services may credit wallets; gateway override must not be exposed via REST/gRPC |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | WalletService.creditWallet gateway parameter | mitigate | Parameter typed as discriminated union `'PAYSTACK' \| 'FLUTTERWAVE' \| 'INTERNAL'` — TypeScript and class-validator reject any other value at compile/transport boundaries; method is only callable from within same NestJS process (not exposed via controller) |
| T-03-02 | Information Disclosure | RedisService.geosearch returning all driver IDs in radius | accept | Driver IDs are internal opaque UUIDs; pairing with PII happens only in TransportService after authorization check |
| T-03-03 | Tampering | Driver model `status` field manipulated by non-admin | mitigate | Schema enforces `DriverStatus` enum; status updates restricted to `@Roles(UserRole.LGA_ADMIN)` controller routes (enforced in Plan 05) — schema-level constraint here ensures invalid values rejected at DB layer |
| T-03-04 | Repudiation | Driver disputes earnings credit | mitigate | Transaction table preserves balanceBefore/balanceAfter + reference (ISY-DRV-*) + module='transport' + new gateway='INTERNAL'; full audit trail per row |
</threat_model>
