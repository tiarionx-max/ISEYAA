<!-- Patterns for load test scripts. Extracted from RESEARCH.md and PATTERNS.md. -->

Backend API conventions (from CLAUDE.md):
- API prefix: /api/v1
- Auth endpoint: POST /api/v1/auth/login with body { phone, password }
- Auth response shape: { data: { accessToken: string } }
- Wallet endpoint: GET /api/v1/wallet/balance (Bearer token required)
- Events endpoint: GET /api/v1/events (public)
- Transport endpoint: POST /api/v1/transport/estimate (Bearer token required)

k6 import syntax (k6 is a Go binary — use k6 JS module syntax, not Node.js):
- import http from 'k6/http'
- import { check, sleep } from 'k6'
- export const options = { ... }
- export default function () { ... }
- Environment injection: __ENV.BASE_URL (not process.env)
- No `require()` — k6 uses ES module imports

Artillery processor.js is Node.js (not k6):
- Uses require('axios') for HTTP
- module.exports = { injectToken }
- Function signature: async function injectToken(context, events, done)
- Token stored in: context.vars.token
- Done signaled with: return done()

Socket.IO event names on TransportGateway (from Phase 3 research):
- join:driver — client joins driver room
- driver:location — emit GPS update { tripId, lat, lng }
- JWT auth via handshake: `handshake.auth.token` (server reads this)
- Artillery socketio engine sends auth via connect options: { auth: { token: '{{ token }}' } }
</interfaces>
