## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mobile UI (TextInput) → POST /users/kyc/bvn | Plaintext BVN crosses HTTPS once; never persisted on device |
| Mobile UI → POST /users/kyc/nin | Plaintext NIN crosses HTTPS once |
| Mobile → AsyncStorage | KYC inputs are NEVER persisted; state lives only in component memory |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-25 | Information Disclosure | BVN/NIN cached in TextInput autofill | mitigate | Use `autoComplete="off"`, `keyboardType="number-pad"`, `textContentType="none"` on iOS/Android |
| T-05-26 | Information Disclosure | BVN/NIN visible in console.log | mitigate | Plan forbids logging; code review verifies no `console.log(bvnInput)` |
| T-05-27 | Spoofing | Request without JWT | mitigate | mobile/lib/api.ts auto-injects JWT; backend rejects unauthenticated calls |
| T-05-28 | Tampering | User self-skips Tier 1 by tapping disabled Tier 2 | mitigate | UI guard: locked-state Tier 2 renders no input/CTA; backend would also reject because bvnHash missing |
| T-05-29 | Elevation of Privilege | Liveness completion via stub without real verification | accept (MVP) | Logged at backend with [SMILE STUB] tag; Wave 7 checkpoint flags this for production gating |
</threat_model>
