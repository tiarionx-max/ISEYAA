| C-01 | `backend/src/modules/wallet/wallet.service.ts` | 249–267 | **No SELECT FOR UPDATE on debit path — race-condition double-spend.** `creditWallet` uses `prisma.$transaction([update, create])` which is a batch, not an interactive transaction. The `balance` is read outside the transaction (line 246–247), then written inside it. Under concurrent requests two goroutines can both read the same `balance`, both add `amount`, and both write an inflated value — net effect is crediting the wallet twice.
