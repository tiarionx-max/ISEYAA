<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AppCode → ENCRYPTION_KEY (env) | Master key for AES-256-GCM; never logged, never returned in API |
| AppCode → Upstash Vector (HTTP) | Vector index calls go over HTTPS to Upstash REST API |
| AppCode → Paystack/Dojah (HTTP) | BVN/NIN values transit to KYC providers over HTTPS |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04 | Information Disclosure | BVN/NIN appearing in logs | mitigate | Service methods never log dto.bvn or dto.nin — only userId + verified flag; checked via code review in Wave 3 |
| T-05-05 | Tampering | AES-GCM auth-tag stripped, ciphertext modified | mitigate | EncryptionService stores authTag separately; decrypt throws on tamper (test in Task 1 verifies) |
| T-05-06 | Tampering | Upstash Vector filter injection via userId | mitigate | userId comes from JWT (req.user.userId) — never user-supplied; documented comment above filter string |
| T-05-07 | Information Disclosure | ENCRYPTION_KEY committed to git | mitigate | `.env.example` placeholder is all-zeros; real key is operator-supplied at deploy time; `.env` is gitignored |
| T-05-08 | Denial of Service | Upstash Vector downtime takes chat path down | mitigate | upsertInteraction is fire-and-forget (try/catch + return); getPersonalisedContext returns '' on error — never throws into the SSE response |
</threat_model>
