<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mobile UI → expo-secure-store | Access token read from hardware-backed secure enclave |
| Mobile → Backend SSE | JWT in Authorization header; body sent over TLS |
| Mobile → AsyncStorage | Chat history at rest on device — not encrypted (UI-SPEC accepts) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-21 | Information Disclosure | AsyncStorage chat history readable by rooted device | accept | Chat content is non-sensitive (Ogun State info); no PII transmitted by design. UI-SPEC line 622 explicitly approves AsyncStorage |
| T-05-22 | Spoofing | SSE request without JWT | mitigate | Backend's `@UseGuards(JwtAuthGuard)` rejects unauthenticated calls; mobile reads token from SecureStore before opening EventSource |
| T-05-23 | Tampering | Malformed SSE payload crashes RN runtime | mitigate | `try/catch` around `JSON.parse(event.data)`; unknown fields ignored; explicit `'[DONE]'` sentinel check |
| T-05-24 | Denial of Service | User opens screen and chat history grows unbounded | mitigate | Hard cap at 100 messages via `slice(-100)` on every persist |
</threat_model>
