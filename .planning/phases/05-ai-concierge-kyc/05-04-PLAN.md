## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mobile → POST /ai/chat | User-supplied text + JWT |
| AiService → Anthropic API | System prompt + user history sent over HTTPS |
| AiService → Prisma (tool execution) | Server-controlled queries; no user-supplied SQL |
| AiService → Upstash Vector | Filter uses JWT-derived userId (not user input) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-15 | Tampering | Prompt injection — user asks AI to ignore prior instructions | mitigate | System prompt established before user messages; tools are read-only Prisma queries (no admin write surface); Claude tool definitions explicitly scope each tool to a domain |
| T-05-16 | Information Disclosure | AI leaks another user's data via tool result | mitigate | Tools query public listings only (isActive, status:PUBLISHED) — never wallet, transactions, KYC, or other-user PII |
| T-05-17 | Denial of Service | Unbounded tool loop on adversarial input | mitigate | Hard cap of 3 turns; max_tokens=1024 per turn; SSE response is bounded |
| T-05-18 | Information Disclosure | Anthropic logs the user message server-side | accept | Standard provider risk acknowledged in CLAUDE.md / RESEARCH; mitigated by Anthropic enterprise privacy controls (out of phase scope) |
| T-05-19 | Tampering | Upstash Vector filter injection via userId | mitigate | userId is req.user.userId (JWT) — never from body; VectorService already documents this guard |
| T-05-20 | Information Disclosure | accumulatedText (full AI response) upserted to vector includes sensitive recommendations | accept | Vector index is per-user; filter `userId = '${userId}'` scopes reads; Upstash deletes on account erasure flow (Phase 6) |
</threat_model>
