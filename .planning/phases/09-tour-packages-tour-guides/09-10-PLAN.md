<interfaces>
NEW Backend endpoints (added inside this plan):

  GET /api/v1/admin/tours/revenue?packageId=<uuid>&from=<iso>&to=<iso>
    -> {
         totalAmountNgn: number,
         packageName: string,
         vendorBreakdown: [{ vendorType, vendorId, vendorName, totalCreditedNgn, transactionCount }],
         platformCommissionNgn: number,
         bookingCount: number,
       }
    Implementation:
      - Find all tour_bookings.id where tourPackageId = ? AND createdAt BETWEEN from..to AND status='CONFIRMED'.
      - Find all transactions where metadata.module='tour' AND metadata.bookingId IN (...) AND type='CREDIT'.
      - Group by metadata.vendorType + metadata.vendorId.
      - Sum amount.
      - Platform commission = sum of transactions where reference endsWith '-PLAT'.

  GET /api/v1/admin/tours/utilization?from=<iso>&to=<iso>
    -> {
         buckets: [
           { date: 'YYYY-MM-DD', groupSizeBucket: '1-2'|'3-5'|'6-9'|'10-24'|'25-50', bookingCount: number, totalPassengers: number }
         ]
       }
    Implementation:
      - SELECT date_trunc('day', tour_date) AS date,
               CASE
                 WHEN passenger_count <= 2 THEN '1-2'
                 WHEN passenger_count <= 5 THEN '3-5'
                 WHEN passenger_count <= 9 THEN '6-9'
                 WHEN passenger_count <= 24 THEN '10-24'
                 ELSE '25-50'
               END AS bucket,
               COUNT(*), SUM(passenger_count)
        FROM tour_bookings WHERE status='CONFIRMED' AND deleted_at IS NULL AND tour_date BETWEEN from..to
        GROUP BY 1, 2 ORDER BY 1, 2;
