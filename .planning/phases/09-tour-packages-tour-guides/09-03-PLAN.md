Stand up the TOUR_GUIDE onboarding pipeline: role assignment, profile management, Tier-2 KYC reusing Phase 5's `EncryptionService` + `DojahService`, availability calendar updates, and LGA_ADMIN approval queue. Closes TOUR-01 backend.

- `availability` shape: `{ blockedDates: string[]; weeklyOffDays: number[] }` (this plan implements the writer).
- TourGuide is 1:1 with User via `userId @unique` (analog to Vendor).
