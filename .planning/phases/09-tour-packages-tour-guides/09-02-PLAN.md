<objective>
Build three shared primitives Wave 2-5 plans will consume:

1. **ReferenceService** — centralize the `ISY-<PREFIX>-<12char-uppercase>` generator currently inlined as `uuidv4().replace(/-/g, '').slice(0, 12).toUpperCase()` in wallet/marketplace/stays/studio/events services. CLAUDE.md mandates the naming convention; a helper removes 6 duplications and gives us a single regex test surface. Plan 09-05 will call `referenceService.generate('TOUR')` to mint `ISY-TOUR-<12char>` references.

2. **RefundService** — wraps Paystack's `POST /transaction/refund` endpoint + writes a `REFUND` Transaction row to the buyer's wallet ledger as a reversal. CONTEXT §Multi-vendor commission split explicitly says: "ANY failure inside the transaction → entire rollback → Paystack refund kicked via existing `RefundService` (or create if missing — flag if it doesn't exist)." Codebase audit (grep confirmed) shows NO RefundService exists. This plan creates it as a Common @Global service so plan 09-06 (settlement engine) can inject it cleanly.

3. **UploadService + UploadController** — addresses PLAN-CHECK M2. ROADMAP SC1 requires TourGuide certifications as **file uploads** (not URL-input stubs); ROADMAP SC7 requires review photos. Codebase audit confirms S3Service exposes only `upload(key, body, contentType)` (server-side PutObject) — no presigned URL method exists. To avoid funneling user-uploaded bytes through the NestJS process, this plan introduces:
   - `UploadService.createPresignedUploadUrl({ keyPrefix, contentType, maxBytes, userId })` — generates a short-lived (15 min) PUT URL the client uses to upload directly to S3/R2.
   - `POST /api/v1/uploads/presigned` — authenticated endpoint that validates content type + size cap, then returns `{ uploadUrl, key, publicUrl, expiresIn }`.
   - Client-side flow (consumed by 09-03 cert upload + 09-08 review photo upload + 09-09 cover image upload): (a) POST /uploads/presigned with `keyPrefix='tour-certifications'` (or `'review-photos'`, etc.) → receive uploadUrl + publicUrl; (b) PUT the file to uploadUrl directly; (c) POST the final `publicUrl` back to the resource-create endpoint (e.g. PATCH /tour-guides with certifications: [publicUrl]).
   - Requires the `@aws-sdk/s3-request-presigner` package (sibling of the already-installed `@aws-sdk/client-s3` — npm add during execution).

The reason all three ship together in Wave 1: they have ZERO codebase deps on Phase 9 schema. They unblock 09-03 (cert upload UX), 09-05 (booking uses ReferenceService), 09-06 (settlement uses RefundService), and 09-08 (review photo upload) without forcing those plans to also build infrastructure. Parallel-safe with 09-01: file lists are completely disjoint (09-01 touches schema/seed; 09-02 touches common services + a new common/controllers dir).

```typescript
async refundCharge(reference: string, amountKobo?: number, reason?: string): Promise<{
  id: string;
  amount: number;       // kobo
  status: string;       // 'pending' | 'processed' | 'failed'
}> {
  const secretKey = this.config.get<string>('PAYSTACK_SECRET_KEY', '');
  if (!secretKey) {
    this.logger.warn('PAYSTACK_SECRET_KEY not set — refund stubbed in dev');
    return { id: `stub_${reference}`, amount: amountKobo ?? 0, status: 'pending' };
  }
  const body: Record<string, any> = { transaction: reference };
  if (amountKobo) body.amount = amountKobo;
  if (reason) body.customer_note = reason;
  try {
    const { data } = await axios.post('https://api.paystack.co/transaction/refund', body, {
      headers: { Authorization: `Bearer ${secretKey}`, 'Content-Type': 'application/json' },
      timeout: 10_000,
    });
    return { id: String(data.data.id), amount: Number(data.data.amount), status: String(data.data.status) };
  } catch (err: any) {
    this.logger.error(`Paystack refund failed for ${reference}`, err?.response?.data ?? err.message);
    throw new ServiceUnavailableException('Refund gateway unavailable. Retry queued.');
  }
}
```

```typescript
@Injectable()
export class RefundService {
  private readonly logger = new Logger(RefundService.name);

  constructor(
    private prisma: PrismaService,
    private paystack: PaystackService,
    private referenceService: ReferenceService,
  ) {}

  async refund(input: RefundInput): Promise<RefundResult> {
    const refundRef = `${input.paystackReference}-RFND`;

    // Idempotency: replay-safe — if we already wrote this REFUND row, return it.
    const existing = await this.prisma.transaction.findUnique({ where: { reference: refundRef } });
    if (existing) {
      return {
        refundReference: existing.reference,
        paystackRefundId: existing.gatewayRef ?? '',
        amountRefunded: Number(existing.amount),
        status: 'SUCCESS',
        transactionId: existing.id,
      };
    }

    const amountKobo = input.amountKobo;
    const amountNgn = amountKobo / 100;

    // 1. Call Paystack refund endpoint
    const paystackResult = await this.paystack.refundCharge(
      input.paystackReference,
      amountKobo,
      input.reason,
    );

    // 2. Write REFUND Transaction row on buyer wallet — SELECT FOR UPDATE for consistency
    const txn = await this.prisma.$transaction(async (tx) => {
      await tx.$executeRaw`SELECT id FROM wallets WHERE id = ${input.walletId} FOR UPDATE`;
      const wallet = await tx.wallet.findUnique({ where: { id: input.walletId } });
      if (!wallet) throw new NotFoundException('Wallet not found for refund');

      // Note: this REFUND row records the gateway-side reversal. It does NOT touch wallet.balance
      // (the original charge never credited the buyer wallet — Paystack returns money to the card).
      // We write a zero-balance-delta REFUND row purely as a ledger marker for audit + idempotency.
      const balance = Number(wallet.balance);
      return tx.transaction.create({
        data: {
          walletId: input.walletId,
          type: 'REFUND',
          status: paystackResult.status === 'processed' ? 'SUCCESS' : 'PENDING',
          amount: amountNgn,
          currency: 'NGN',
          reference: refundRef,
          gateway: 'PAYSTACK',
          gatewayRef: paystackResult.id,
          description: input.reason ?? 'Refund issued',
          balanceBefore: balance,
          balanceAfter: balance,                     // unchanged — money goes back to card not wallet
          metadata: { ...input.metadata, module: 'refund', originalReference: input.paystackReference },
        },
      });
    });

    return {
      refundReference: refundRef,
      paystackRefundId: paystackResult.id,
      amountRefunded: amountNgn,
      status: paystackResult.status === 'processed' ? 'SUCCESS' : 'PENDING',
      transactionId: txn.id,
    };
  }
}
```

Important behavioral notes for the executor:
- The REFUND Transaction has `balanceAfter === balanceBefore` because Paystack returns the money to the original card, not to the user's in-app wallet. The row exists purely as a ledger marker (for audit + idempotency check).
- If a future flow needs to credit the wallet instead of the card (e.g. promo refund), that's a separate `creditWallet` call — NOT this service's job.
- Idempotency is keyed on `${paystackReference}-RFND` — a single original Paystack reference can have at most one refund record from this service.

```typescript
export const ALLOWED_UPLOAD_CONTENT_TYPES = [
  'image/jpeg',
  'image/png',
  'image/webp',
  'application/pdf',
] as const;

export const MAX_UPLOAD_BYTES_DEFAULT = 5 * 1024 * 1024;
export const MAX_UPLOAD_BYTES_HARD_CAP = 25 * 1024 * 1024;
export const PRESIGNED_URL_EXPIRY_SECONDS = 900;

const EXTENSION_BY_CONTENT_TYPE: Record<string, string> = {
  'image/jpeg': 'jpg',
  'image/png': 'png',
  'image/webp': 'webp',
  'application/pdf': 'pdf',
};

export interface CreatePresignedUploadInput {
  keyPrefix: UploadKeyPrefix;
  contentType: string;
  maxBytes?: number;
  userId: string;
}

export interface PresignedUploadResult {
  uploadUrl: string;
  key: string;
  publicUrl: string;
  expiresIn: number;
  maxBytes: number;
}

@Injectable()
export class UploadService {
  private readonly logger = new Logger(UploadService.name);

  constructor(private s3Service: S3Service, private config: ConfigService) {}

  async createPresignedUploadUrl(input: CreatePresignedUploadInput): Promise<PresignedUploadResult> {
    // 1. Validate contentType (DTO already enforces, but defense-in-depth in case service is called directly)
    if (!ALLOWED_UPLOAD_CONTENT_TYPES.includes(input.contentType as any)) {
      throw new BadRequestException(`Unsupported contentType: ${input.contentType}`);
    }

    // 2. Cap maxBytes
    const maxBytes = Math.min(input.maxBytes ?? MAX_UPLOAD_BYTES_DEFAULT, MAX_UPLOAD_BYTES_HARD_CAP);
    if (maxBytes <= 0) throw new BadRequestException('maxBytes must be positive');

    // 3. Refuse if S3 is unconfigured
    if (this.s3Service.getMode() === 'unconfigured') {
      throw new ServiceUnavailableException('Object storage not configured — set AWS_* or R2_* env vars');
    }

    // 4. Server-controlled key: prefix/userId/uuid.ext (NEVER trust caller-supplied paths)
    const ext = EXTENSION_BY_CONTENT_TYPE[input.contentType] ?? 'bin';
    const key = `${input.keyPrefix}/${input.userId}/${uuidv4()}.${ext}`;

    // 5. Sign the PutObject command — 15-minute expiry
    const cmd = new PutObjectCommand({
      Bucket: this.s3Service.getBucket(),
      Key: key,
      ContentType: input.contentType,
      ...(this.s3Service.getMode() === 'aws' && { ACL: 'public-read' as const }),
    });
    const uploadUrl = await getSignedUrl(this.s3Service.getClient(), cmd, {
      expiresIn: PRESIGNED_URL_EXPIRY_SECONDS,
    });

    // 6. Compute the publicUrl using the same logic as S3Service.upload()
    const cdnBase = this.s3Service.getCdnBase();
    let publicUrl: string;
    if (cdnBase) {
      publicUrl = `${cdnBase}/${key}`;
    } else if (this.s3Service.getMode() === 'aws') {
      const region = this.config.get<string>('AWS_REGION', 'af-south-1');
      publicUrl = `https://${this.s3Service.getBucket()}.s3.${region}.amazonaws.com/${key}`;
    } else {
      const accountId = this.config.get<string>('CF_ACCOUNT_ID', '');
      publicUrl = `https://${accountId}.r2.cloudflarestorage.com/${this.s3Service.getBucket()}/${key}`;
    }

    return { uploadUrl, key, publicUrl, expiresIn: PRESIGNED_URL_EXPIRY_SECONDS, maxBytes };
  }
}
```
