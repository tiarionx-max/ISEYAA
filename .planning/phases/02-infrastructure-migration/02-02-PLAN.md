<objective>
Migrate all file storage from AWS S3 + CloudFront to Cloudflare R2. The change is surgical: only the S3Client constructor in S3Service changes. All upload(), getSignedUrl(), and other method bodies remain identical because R2 is S3-compatible.

Purpose: Eliminate AWS egress fees (~$0.09/GB) and reduce cloud costs. R2 has zero egress. Existing S3 SDK call sites in all feature services require no changes.
Output: Updated S3Service constructor targeting R2 endpoint, unit tests verifying the R2 config, updated .env.example documenting R2 env vars and removing old AWS vars.
</objective>
