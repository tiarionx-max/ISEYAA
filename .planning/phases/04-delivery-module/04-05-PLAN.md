<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WebSocket handshake → DeliveryGateway | JWT verified in handleConnection before any room joins or event handling |
| HTTP request → DeliveryController | JwtAuthGuard + RolesGuard enforced per route; fee-estimate is intentionally public |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-14 | Spoofing | DeliveryGateway.handleConnection | mitigate | JWT verified via JwtService.verify(); invalid/expired tokens → client.disconnect() immediately; same pattern as TransportGateway |
| T-04-15 | Information Disclosure | rider:location events leaking across deliveries | mitigate | handleRiderLocation relays ONLY to `delivery:${deliveryId}` room (not server.emit() globally); room scoping enforced by socket.io room membership |
| T-04-16 | Elevation of Privilege | Non-DRIVER joining rider: room | mitigate | handleJoinRider checks `client.data.role !== 'DRIVER'`; returns `{ error: 'forbidden' }` if role check fails |
| T-04-17 | Tampering | AppModule with two gateways on same server | accept | NestJS merges multiple @WebSocketGateway() instances on the same HTTP server when no port is specified; room name prefixes (delivery: vs trip:) prevent event collisions |
</threat_model>
