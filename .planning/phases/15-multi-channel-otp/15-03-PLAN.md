Implement the actual channel-selection, WhatsApp send, and fallback-to-SMS logic in `AuthService` — the core of this phase. Resolve the effective channel (returning user's persisted preference wins over a fresh request; default SMS), thread that channel (and, for EMAIL, the target address) through Redis so it survives the gap between `otp/send` and `phoneAuth`'s user-creation step, add a new `sendMetaWhatsapp()` method replacing Termii's old WhatsApp passthrough, route BOTH non-SMS channels through `resilience.execute()`, and make every failure of a non-SMS channel fall through to the exact same OTP code via Termii SMS.
