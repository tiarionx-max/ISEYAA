| `PlatformConfig.tour.government_wallet_user_id` → SettlementService callers | Every settlement caller trusts this value as the Ministry's real wallet-owning user id — must never be settable via any client-facing endpoint in this phase (it is admin-controlled through the existing `PATCH /admin/config/:key` route, unchanged by this plan) |
