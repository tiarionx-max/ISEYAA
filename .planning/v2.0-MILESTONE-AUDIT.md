Sentry/OTel initialization is likewise monolith-only, so RESIL-02's observability path has no reach into any future extracted service either — same root cause, same fix.

**Not a blocker today** because Phase 17 (the only phase that will actually run these scaffolds) hasn't started. **Recommend**: fold "wire ResilienceModule + Sentry/OTel bootstrap into extracted services" into Phase 17's scope, or address it as a small standalone fix before Phase 17 planning starts.
