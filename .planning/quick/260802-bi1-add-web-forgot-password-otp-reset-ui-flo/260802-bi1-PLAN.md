header with Image + text-gradient-gold wordmark, `glass rounded-3xl p-7` card, footer
copyright line). Import from the same modules already used in login/register:

Define `const API_URL = process.env.NEXT_PUBLIC_API_URL ?? 'http://localhost:3001/api/v1';`
matching register/page.tsx line 13.

State: `step` (1 | 2), `phone`, `otp`, `newPassword`, `showPw`, `loading`.

Step 1 (request OTP) — render a phone input (type tel, autoComplete tel, placeholder
"+2348012345678"). On submit: client guard `phone.trim()` non-empty (else
toast.error and return); set loading; `await axios.post(`${API_URL}/auth/otp/send`,
{ phone })`; on success toast.success('OTP sent to your phone') and setStep(2); catch
mirrors register error handling (read err?.response?.data?.message, join array with
', ', else fallback 'Failed to send OTP. Please try again.'); finally clear loading.
Submit button uses the login spinner markup while loading (label "Sending code...").

Step 2 (reset) — render a 6-digit OTP input (inputMode numeric, maxLength 6,
placeholder "6-digit code") and a new-password input with the Eye/EyeOff show/hide
toggle copied from login/page.tsx (minLength 8, autoComplete new-password). On submit:
client guards — `otp.length === 6` (else toast.error 'Enter the 6-digit code' and
return) and `newPassword.length >= 8` (else toast.error 'Password must be at least 8
characters' and return); set loading; `await axios.post(`${API_URL}/auth/reset-password`,
{ phone, otp, newPassword })`; on success toast.success('Password reset. Please sign
in.') and `router.push('/login')`; catch mirrors register error handling (fallback
'Failed to reset password. Please try again.'); finally clear loading. Submit button
uses spinner markup while loading (label "Resetting...").

Do NOT attempt next-auth signIn — we only have phone, not the email the credentials
provider needs. Just redirect to /login on success.

Include a "Back to sign in" Link to /login styled with the gold/muted link treatment
(`text-gold/80 hover:text-gold`) matching the register/login footer prompt. On step 2,
optionally add a small "Change number" affordance that calls setStep(1) — nice-to-have,
keep minimal.

Update the header subtitle text to reflect the step (e.g. "Reset your password" /
"Enter the code we sent"). TypeScript strict, 2-space indentation, no `any` except the
`catch (err: any)` used in the reference files.

Do NOT place any fenced code blocks in this file beyond the actual component source.
