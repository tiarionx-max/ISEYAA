User confirmed via live testing that the Create Event screen's "Create event" button stayed disabled after typing values into all visible fields. Root cause: the "LGA ID" field was a raw free-text input expecting a literal LGA UUID (placeholder "LGA UUID"), which no real organiser would know — a pre-existing, explicitly flagged simplification ("Known simplification: no LGA picker component exists anywhere in mobile yet"). The same exact pattern existed verbatim in `event-edit/[id].tsx` and `property-create.tsx`.

Purpose: Every user creating/editing an event or property listing must be able to pick a real LGA without knowing its UUID.
Output: All three screens now fetch `GET /lgas` (existing, unauthenticated, 20-record endpoint) and render a horizontally-scrollable row of the existing shared `Chip` component (`mobile/components/ui/Chip.tsx`, already used by `property-create.tsx` elsewhere) — tapping a chip sets the form's `lgaId` state to that LGA's real id. The old raw-UUID `TextInput` and its "known simplification" comment are removed from all three files.
</objective>
