# Quick Task 260727-8v6: Marketplace/Tourism image upload + mobile display wiring Summary

**Added VENDOR-gated product image upload and SUPER_ADMIN/LGA_ADMIN-gated attraction image upload endpoints (mirroring the existing EventsController.uploadImage pattern), wired mobile events/attraction cards to display real photos via expo-image with gradient fallback, and configured a placeholder Android notification icon.**

## Accomplishments

- `POST /products/:id/images` — VENDOR can upload a jpg/png/webp (≤5MB) image for their own product; resized to 1200x1200 webp and appended to `Product.imageUrls`. Rejects with `NotFoundException`/`ForbiddenException` for missing/not-owned products.
- `POST admin/attractions/:id/images` — SUPER_ADMIN/LGA_ADMIN can upload an image for any attraction (no ownership concept); resized to 1200x630 webp and appended to `Attraction.imageUrls`.
- Mobile events detail hero, events list cards (Book tab), and Discover-tab attraction cards now render the real `imageUrls[0]` photo via `expo-image` when present, falling back to the existing gradient placeholders otherwise. The attraction card's bookmark heart button still renders on top in both branches.
- Android notification icon configured: a placeholder 96x96 transparent PNG (white circle) plus `app.json`'s `expo-notifications` plugin entry converted to tuple form with `icon`/`color` (#1A6B3C FOREST).
