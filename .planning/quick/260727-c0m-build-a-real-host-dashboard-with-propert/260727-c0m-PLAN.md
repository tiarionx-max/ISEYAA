## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Mobile app → `POST`/`PATCH /properties*` | Host-supplied listing data (name, type, prices, address, coordinates) crosses into Prisma writes |
| Mobile app → `GET /properties/mine` | Must never return another host's properties |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-quick-01 | Tampering (enum bypass) | `CreatePropertyDto`/`UpdatePropertyDto` | mitigate | `@IsEnum(PropertyType)`/`@IsEnum(BookingMode)` validate directly against the real Prisma-generated enums (imported from `@prisma/client`, not a hand-copied subset) — global `ValidationPipe` (`whitelist: true, forbidNonWhitelisted: true`) rejects any other value or unknown field |
